# 烽火 LG6121F 云登录与远程短信：脱敏开发记录

## 项目标识

- 中文名称：烽火云短信助手（非官方）
- 厂商 / 型号：FiberHome LG6121F CPE
- 实机固件记录：RP0108
- 范围：账号登录、绑定设备筛选、手动读取收件/发件短信、用户主动发送短信。
- 开发来源：公开烽火终端客户端行为观察、脱敏网络记录，以及既有项目内已确认的烽火短信能力；由 OpenAI 辅助开发和整理。

## 已有依据与当前状态

1. 原有整合项目的烽火云账号登录曾有真实请求成功样本；登录密码摘要与云请求签名有离线逐字段核对记录。
2. 烽火远程短信收发在既有整合 App 中曾由用户确认可用。
3. 现独立客户端是为公开仓库重新整理的最小实现：仅保留短信相关云操作，命令固定为 `SMS_UPGRADE_MESSAGE`、`SMS_GET_MESSAGE`、`SMS_SEND_MESSAGE`。
4. 设备列表对外只输出名称/型号/索引，内部网络地址和 MAC 不进入演示 API。
5. 本次仓库创建没有执行真实账号登录、云请求、OTP、短信发送或设备控制。

**结论：既有整合版短信功能有实机使用依据；公开仓库里的独立提取组件尚未完成真实端到端验证。**两者不能混称为“独立组件已上线”。

## 不公开、不实现的内容

- 中兴 MU5120 / ZTE 账号或云控制协议。
- 任何远程状态读取、Wi‑Fi 信息/写入、网络制式、信号/流量、远程重启或固件升级。
- 解绑设备、删除短信、通用命令转发、任意 RPC、后台轮询、自动发送。
- API key、静态客户端秘密值、账号数据、真实手机号、短信、设备 MAC/序列号和原始抓包。

## 离线验证计划

- 检查设备筛选仅收录 `LG6121F`，其余型号不能传入短信 API。
- 注入合成 HTTP 响应，验证登录、Keychain 会话处理、收件/发件索引解析、短信编码和“接受请求≠送达”结果语义。
- 恶意/意外命令与额外参数必须在发请求前拒绝。
- 运行 Objective‑C iOS SDK 语法检查与脚本白名单扫描；不连接网络。

## 仍需完成

- 在明确授权的新测试账户与 LG6121F 上端到端验证独立登录、设备列表及收/发短信。
- 确认失败码、账号锁定、地区限制、验证码/二次校验和令牌过期行为。
- 用真实发件箱复核接受状态；在没有厂商回执的情况下，不宣称已送达。
- 复核账号凭据及令牌仅保存在设备级 Keychain；确认应用日志不包含凭据、短信正文或完整请求。
- 准备 UI 接入、测试矩阵与许可证/厂商服务条款审阅。
