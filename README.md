# 烽火云短信助手（非官方）

**LG6121F 烽火 CPE：独立整理云账号登录与远程收发短信能力。**

本仓库只包含烽火 FiberHome 云端账号登录、绑定设备中筛选 **LG6121F**，以及该设备的远程短信手动读取/发送最小代码。已知实机固件 **RP0108**。它不是完整远程控制 App，也不发布远程状态监控、Wi‑Fi 管理、网络设置、路由器重启、设备解绑、短信删除或固件升级能力。

> 开发说明：本项目在 **OpenAI 辅助下开发**，包含代码整理、协议校对、范围限制及文档/测试辅助；这不是 OpenAI 或烽火官方项目，也不代表厂商背书。仅供设备所有者或获授权用户使用。

## 功能边界

- 明确调用账号密码登录；登录密码按已观察协议做 SHA‑256 十六进制处理；令牌保存在本机 Keychain。
- 查询账号已绑定设备，但只向短信 API 暴露 LG6121F 候选设备；设备 MAC/内部云标识不作为界面字段公开。
- 用户主动调用时读取收件箱或发件箱；没有定时器、后台轮询或推送。
- 用户明确调用时发送一条短信；代码会校验号码/正文长度并按是否含中文选择编码。
- 发送接口成功只表示设备/云端接受请求，**不保证运营商已送达**。应由用户自行刷新已发短信核对。
- 没有删除短信接口；不实现一般设备命令、远程配置或重启接口。

短信只允许以下三种命令，命令与参数均有白名单：

1. `SMS_UPGRADE_MESSAGE`：读取短信索引；
2. `SMS_GET_MESSAGE`：按索引手动读取收/发箱；
3. `SMS_SEND_MESSAGE`：发送用户明确提交的一条短信。

## 设备与验证进度

- **设备**：烽火 FiberHome **LG6121F** CPE。**RP0108** 是现有开发记录中的实机固件。
- 烽火终端 App 登录字段、密码摘要和云端请求签名，曾基于公开客户端静态分析与真实脱敏请求记录作离线核对；这些验证并不表示新客户端已获厂商授权。
- 项目使用的已集成版中，烽火远程短信收发曾由用户确认可用；短信实现是从现有工程中独立整理出来的。
- 本仓库的新独立 `FiberHomeSMSClient` 尚未用真实烽火云账号完成端到端验证；本次整理未发云请求、未发送短信，也未读取用户令牌/密码。
- 因此：**现有整合版短信能力有实测依据；本仓库中的独立移植仍是待复验的开发版本。**登录、型号筛选及新建仓库构建出的集成 App 均需后续验证。

- `examples/短信页面接入示例.m`：需由界面按钮显式调用的接入示例；不自动发送。
- `文档/开发记录.md`：来源、当前进度和不足。
- `技能/烽火云短信开发.md`：后续维护使用的范围与测试技能。
- `tests/离线边界检查.py`：验证公开源文件只保留短信命令白名单。

## 集成方式

在 iOS Objective‑C 工程中添加 `src/FiberHomeSMSClient.m` 和对应头文件，并链接 Foundation、Security、CommonCrypto。页面必须由用户主动点击登录、刷新收件箱/发件箱或发送按钮后调用。参见 `examples/短信页面接入示例.m`。

账号密码、短信验证码（如厂商后续要求）、手机号、短信正文、令牌、MAC 与完整 API 请求都不得写入日志、仓库、崩溃报告或分析事件。退出时调用 `logout`。该最小客户端采用同步等待封装，**不可在 UIKit 主线程直接调用**；请从串行后台队列发起，完成后再回主线程更新 UI。

## 不足与后续需要

1. 新提取组件尚未在真实账号/云端复验登录、LG6121F 列表筛选与收发短信。
2. 设备在线状态、不同账号、家庭/多设备绑定、地区版本、厂商 API 变化均未建立兼容矩阵。
3. 未证实令牌有效期、刷新机制和账号锁定策略；错误码/验证码挑战需由授权账户谨慎测试。
4. 送达回执没有实现；仅能说明请求被接受，需手动检查发件箱。
5. UI、安装签名、自动化单元测试及第三方安全审查不在当前最小组件内。
6. 使用厂商云服务的合规性、服务条款和应用分发许可需由维护者自行确认；本仓库不提供账户、云权限或服务可用性保证。
